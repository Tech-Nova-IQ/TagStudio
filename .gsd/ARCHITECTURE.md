## Overview

**TechNova Tag Studio** is a full-stack Spring Boot and vanilla web application designed for YouTube creators to generate optimized hashtags, keywords, video metadata (titles, descriptions, CTAs), playlist descriptions, and conversational AI assistance.

The application combines a deterministic rule-based template engine (generating structured sets of 30 tags per category across 11 categories) with Google Gemini AI (`gemini-3.8-flash`) for creative query assistance and context-aware suggestions.

## Data Flow

1. **Tag & Metadata Generation:**
   - User inputs channel name, topic, and selects categories in `index.html`.
   - `app.js` issues `POST /api/tags/generate` with `TagStudioRequestDTO`.
   - `TagStudioApiController` delegates to `TagGeneratorService.generateStudioData()`.
   - `TagGeneratorService` resolves topic tokens into 11 template buckets (30 items each), formats natural language description templates, title permutations, CTA sections, and playlist metadata.
   - Result is serialized to `TagStudioResponseDTO` and displayed across tabs in the UI.

2. **Studio AI Chat Flow:**
   - User submits a prompt in the chat widget.
   - `app.js` posts history to `POST /api/chat` with `ChatRequestDTO`.
   - `ChatService` performs duplicate check against `recentQueries` (60s cache).
   - `ChatService` resolves `GEMINI_API_KEY` (properties -> environment -> Windows HKCU registry fallback).
   - Request is formatted using OpenAI-compatible payload schema and sent to Gemini endpoint.
   - Responses (or parsed rate limit/quota error structures) return to `app.js` to render markdown messages.

3. **YouTube Activity Lookup:**
   - Query term sent to `GET /api/youtube/activity?q={query}`.
   - `YoutubeActivityService` estimates volume based on keyword characteristics and returns `YoutubeActivityDTO`.

## Technical Debt & Observations

- [ ] **Standalone Prototype Duplication:** `hashtag_generator.html` (1,672 lines in root) is a legacy single-file prototype containing duplicate CSS/JS that has since been migrated to `src/main/resources/`.
- [ ] **Simulated YouTube Metrics:** `YoutubeActivityService` uses hash-based view simulation rather than the official Google YouTube Data API v3.
- [ ] **In-Memory Cache Eviction:** `ChatService.recentQueries` (`ConcurrentHashMap<String, Long>`) lacks a scheduled eviction policy or max size limit, creating an unbounded in-memory cache over long uptimes.
- [ ] **Test Coverage:** Only `ChatServiceTest.java` exists. Missing integration tests (`@WebMvcTest` or `@SpringBootTest`) for `TagStudioApiController`, `YoutubeApiController`, and `TagGeneratorService`.
- [ ] **Stateless Chat Context:** Conversation history is maintained entirely on the client side (`app.js`) without backend session storage or persistence.
